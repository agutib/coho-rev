## 📋 Daily Task Report Standards (Recipient: Mike, CEO)

### 1. Mandatory Email Subject Format
- Format: `[ Daily Task Report — YYYY-Mm-DD ]`
- Examples:
  - Single day: `[ Daily Task Report — 2026-Sep-16 ]`
  - Date range: `[ Daily Task Report — 2026-Sep-03 and 04 ]`

### 2. Mandatory Two-Bucket Report Structure
Every report MUST contain exactly two sections:
1. **Progress:** (completed work during shift)
   - Primary bullet: `•`
   - Secondary sub-bullet: `o` (used for breakdowns such as client codes, invoice numbers, or recipient details)
2. **Plans/To-Do:** (next actions or pending items)
   - Primary bullet: `•`

### 3. Strict Tone & Formatting Rules
- **ZERO greetings**: Never include "Hi Mike", "Good morning", or pleasantries.
- **ZERO sign-offs**: Never include "Best, Rev", "Thanks", or signatures.
- **ZERO narrative filler**: No intro or concluding summaries (e.g. "Today was productive...").
- **Clipped task-log tone**: Short, clear, past-tense for Progress ("Reviewed", "Emailed", "Recorded", "Reconciled").
- **Deduplication**: If an item is mentioned multiple times or overlaps with a checked recurring task, consolidate into one clean bullet.
- **Zero COHO crossover**: Never mention UK HMOs, tenancies, landlords, ASTs, or room numbers.
